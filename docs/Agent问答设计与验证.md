# Agent 问答设计与验证

版本：2026-09-29-v2。此文描述当前实现，替代早期“模型只做规划和段落选择”的能力描述。

## 问题与设计

截图中的“ai安全是什么”被拒答，因为旧问答流程把所有答案都限定为本地检索结果，且模型提示词明确禁止回答。此前增加排序只能修复列表相关性，无法解决概念解释和分析表达。这次调整了路由、生成契约、校验、上下文和界面说明。

赛题设计基线中的 R03 要求理解自然语言、关联跨文档证据并可追溯问答；R04 要求论文、标准和政策知识底座；R05 鼓励可审计编排。本次针对问答层增强，不将提示词变更宣称为全部赛题指标完成。

| 问题 | 行为 | 依据 |
| --- | --- | --- |
| AI 安全是什么、提示词注入原理 | GLM 直接解释，允许例子和防御思路 | 标记模型通识，不伪造引用或实时核验 |
| 举个例子、怎么防范 | 传递最近一轮概念问答以理解指代 | 只传概念历史，不附带资产记录 |
| 某 CVE 的机制、影响、修复 | 本地定位来源，GLM 读取公开正文并解释；附结构化核对记录 | 逐段原文引用，保持来源差异和不确定性 |
| 当前有哪些高危漏洞 | 产品主题筛选、严重度筛选、去重、候选排序、证据分析 | 说明本地数量、展示上限与来源时间 |
| 某组织资产是否受影响 | 本地版本匹配及证据输出 | 不发送登记资产给综合模型 |
| 未入库 CVE 的修复版本 | 明确缺少证据 | 不用模型记忆填补具体情报 |

## 提示词与校验

`app/prompts.py` 保存概念解释和证据综合提示词。概念解释禁止生成具体漏洞编号、补丁版本、伪造引用和链接。证据综合要求只使用给定公开卡片，每段输出正文、引用编号及原文连续摘录；英文公告可解释为中文，推断或建议需明确表达其前提。

程序校验结构、引用白名单、原文摘录、CVE/GHSA 和版本/评分形式的数值一致性。失败后最多请求一次修正，仍失败则回退本地证据。综合过程只发送问题和公开文档白名单字段，不发送 raw、资产表、完整数据库或检索生成的资产结论。

这些校验能拦截错编号、假引文和部分数值错误，但**不能证明中文概括在语义上完全受原文支持**。保留结构化证据是为了便于复核；独立留出题集、人审准确率、冲突判断和多跳泛化仍未完成。模型也没有因此获得自主联网采集、扫描或执行工具的能力。

## 验证

`tests/test_answer_modes.py` 覆盖截图原问题、概念追问、具体事实路由、服务异常回退、伪造引用、错原文、错误版本（含版本子串误命中）、一次修正、资产输入隔离和综合失败回退。前端仍保留输入法组合输入回车保护。

真实 GLM 冒烟已验证“ai安全是什么”可解释、追问可接续，以及未知 CVE 保持拒答。初次具体漏洞分析出现引用校验回退；后续直接核验得到附两份来源的机制和修复解释，故增加了一次有界格式/引用修正。最终服务验收结果以本次会话中的 HTTP 验证为准。单条调用耗时与成功不能当作竞赛正确率或延迟达标证据。

本轮全量回归为 84 项通过。真实 HTTP 示例中，“ai安全是什么”返回 `concept_explanation`（约 6.27 秒）；Ollama 漏洞机制与修复问题返回 `planning+evidence_synthesis`（约 7.97 秒），引用两份来源；盘点问题曾返回规划、排序与综合三个阶段（约 17 秒）。这些是单次开发观察，不能推断 p95。

验收发现正文修复描述和结构化修复字段可能不同步，已增加具体升级建议的 fixed_versions 校验；多产品段落检查各产品的引用归属，接口路径也必须出现在其所引证据中。允许明确报告正文说法与字段缺失的差异，不直接将未核验版本推荐为补丁。

加强归属校验后的最后一次复杂盘点 HTTP 测试，模型段落的产品引用不完整，修正后仍未通过，约 28.84 秒回退到本地 14 条匹配、8 个引用的结果。随后对同组公开证据的直接调用在一次修正后通过。这说明引用修正有实际作用，也暴露了复杂盘点稳定性与耗时仍需优化；不能把所有真实调用描述为成功综合。
