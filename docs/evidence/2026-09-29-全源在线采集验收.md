## 不能据此声称的成绩

- 10 条任务成功中有一条没有匹配文档；有文档的来源也包括论文、标准、政策与重复的社区媒体。不能把 10/12 直接解释成赛题的「7 类漏洞来源」。
- 此次为一次约两分钟的手动运行，不是连续多日的稳定性试验。当前 441 个可计算时间差的历史补录样本 p50 约 2,203 小时；这个数值描述历史积压，不能用于证明或否定稳定运行后的 ≤6 小时延迟。
- `claims` 数量不是富化准确率。来源字段的抽取、PoC 可用性和跨文档关系仍缺少独立人工真值与误差分析。
- 当前版本匹配只完整支持纯数值区间，预发布版本表达式通常返回 `unknown`；显式枚举的纯数值版本可精确命中，但未命中的版本不应推断为安全。
- HTTP 403 是外部服务或当前网络条件的实际返回。应准备 GitHub Token 或合法替代来源，并持续检查 CISA CERT RSS；不能在报告中把它们算作正常监测源。
