复现命令（需要可访问外网的环境）：

```bash
python3 -m app.cli --db /tmp/zhidun-online-audit2.sqlite3 collect --source cisa_kev
python3 -m app.cli --db /tmp/zhidun-online-audit2.sqlite3 collect --source osv_dev
python3 scripts/export_online_evidence.py --db /tmp/zhidun-online-audit2.sqlite3 --output docs/evidence/online-replay.json.gz
```

`docs/evidence/online-replay.json.gz` 是新运行输出，时间、来源内容和哈希会随重跑变化。导出器只适合**专用公开数据数据库**；不要用于存有私人资产或问答记录的日常数据库。
