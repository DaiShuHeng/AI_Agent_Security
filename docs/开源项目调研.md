# 赛题九：相关开源项目调研与原创设计边界

> 调研对象：第三届“中国电子杯”赛题九《智能体驱动的 AI 安全知识情报系统设计与实现》。下文的“差异”指项目定位与本赛题要求之间的差距，是本作品需要自行解决的问题，不代表对开源项目质量的评价。

## 1. 赛题与调研范围

赛题要求形成“多源持续监测 → AI 安全漏洞富化 → 有证据的跨文档问答”的闭环，另需汇集论文、技术标准与政策法规。富化明确涉及论文与分析文章、受影响资产、PoC、CVSS 与影响评估；优秀作品还要展示增量监测、去重、时效、富化准确率、复杂推理、智能体编排和工程化部署。因此，调研覆盖威胁情报平台、漏洞数据汇聚、AI 安全验证和图谱问答四类项目。

本调研以项目官方 GitHub 仓库的 README、仓库标示的许可证及其文档为依据，核验时间为 **2026 年 9 月 29 日**。许可证只记录仓库有明确声明的版本；具体文件如有单独授权，仍以该文件的许可证头为准。

### 共性发现

1. **统一数据模型决定富化上限。** OpenCTI、MISP 与 Vulnerability-Lookup 均先保存结构化实体、外部标识和来源，再做相关性分析。本作品应将原始材料与推断结果分开存储，避免模型输出覆盖权威公告。
2. **采集与富化适合工具化，但推断需要验收。** IntelOwl 的插件接口与 GPT Researcher 的角色分工可结合：Agent 选择工具和编排任务，确定性的解析、版本匹配、去重和引用校验由程序承担。
3. **“AI 安全”需要双层知识体系。** 基础设施与供应链漏洞适合 CVE/CWE/CVSS/版本模型；提示词注入、数据投毒、Agent 越权等风险可借鉴 ATLAS、garak、PyRIT 的场景分类，不能强制塞进 CVE 字段。
4. **问答质量应以证据和评测衡量。** GraphRAG 提供跨实体检索思路，promptfoo 提供持续评测思路。每项结论要关联原文、发布时间和来源；缺失证据时应明确未知，不能生成虚构 PoC、受影响资产或修复版本。

## 3. 对本作品的选型结论

| 赛题环节 | 拟采用的原创实现路径 | 参考项目 |
| --- | --- | --- |
| 监测 | 自编写多源连接器、游标与增量拉取、原始快照、去重键、任务状态和采集延迟指标。按 CVE/NVD、社区/GHSA、厂商、博客、论文、标准、政策等来源类型分别统计覆盖率。 | Vulnerability-Lookup、MISP、IntelOwl |
| 富化 | 针对漏洞实体运行版本匹配、官方补丁/公告、论文、PoC 元信息、资产台账匹配、CVSS 和利用可能性等富化器；每个结果带证据与置信度。 | OpenCTI、IntelOwl、CTI Butler、garak/PyRIT |
| 问答 | 先做意图解析与实体约束，再结合关键词/语义检索和关系遍历，最后生成带引用的答案、推理链摘要与未知项。 | GraphRAG、GPT Researcher、promptfoo |
| 质量验证 | 用人工标注样本测量采集延迟、富化 precision/recall、版本判断正确率、答案事实性与多跳正确率；对回归样本自动执行。 | PyRIT、promptfoo |

这些仓库是**参考对象**，不是准备拼接成作品的现成模块。尤其需要在自己的代码、数据流程、评测集和演示案例中清楚展示创新工作。

## 4. 原创、许可与数据边界

- **自主实现与署名。** 大赛要求作品原创且拥有自主知识产权。只借鉴公开架构和接口思想；如确需引入第三方代码或数据，记录仓库、版本、许可证、修改范围、原作者与归属，保留要求的版权和 NOTICE 文件。不能把开源系统改名后当作独立参赛成果。
- **注意强互惠许可证。** MISP、IntelOwl、Vulnerability-Lookup 为 AGPL-3.0；本方案以其功能和架构为研究参考，不复制其源码进本项目。若未来决定引入，应先单独评估许可证义务和部署方式。
- **谨慎使用双许可与数据许可。** OpenCTI 仓库声明社区版与企业版许可不同，不能默认所有文件均为 Apache-2.0。知识库中的论文、博客、标准、法规和漏洞公告各有不同的使用条款，应保存链接、摘要和必要元数据，不整篇复制受保护内容。
- **把情报与推断分开。** 记录 `source_url`、`published_at`、`observed_at`、原文哈希、抽取方法、校验状态和 `confidence`。PoC 搜集先记录仓库链接、提交时间和可信度；“存在 PoC”不等于“PoC 已验证”或“漏洞可利用”。
- **受影响资产只做授权范围匹配。** 资产定位优先对用户导入的内部资产台账与受影响版本范围做比对；不得对不属于参赛团队或测试方的公网目标擅自探测、利用或展示敏感细节。
- **演示与指标真实。** 离线样例、模拟监测、真实联网结果需清楚标注。采集延迟、富化准确率、召回率和问答准确率应在可复现实验集上计算，不使用未经验证的“实时”“95%”等宣传数字。
